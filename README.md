### 🧭 What I like working on

- ⚙️ **DevOps & infrastructure**: automating deployments end to end, from a `git push` to a running cluster (Docker, Kubernetes, Ansible, Jenkins, GitHub Actions).
- 🧪 **Testing & reliability**: test suites, CI pipelines and tooling that catch problems before users do.
- 🐚 **Systems programming**: shells, concurrency, IPC, plugin architectures in C and C++.
- 🎨 **Graphics**: raytracing and rendering engines written from scratch.
- 🧠 **Languages & interpreters**: parsing and evaluating my own languages, mostly in Haskell.
- 🎮 **Games**: small multiplayer web games and game jams.
